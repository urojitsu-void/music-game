# Development constraints

- Preserve the Superpowers workflow and TDD.
- Prefer `superpowers:executing-plans` for implementation.
- Do not introduce visual testing frameworks, browser automation, or screenshot testing unless explicitly requested.
- Use existing tests and verification tools whenever possible.
- Do not expand implementation scope based on optional review suggestions.
- Prioritize delivering the requested functionality over unrelated improvements.
- Answer the user's actual question before proposing additional work.
